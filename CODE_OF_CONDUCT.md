# Code of Conduct

## Our standards

Recall Watch contributors and maintainers commit to a respectful, professional and inclusive environment. Participate in good faith, focus on technical evidence, credit others' work and avoid harassment, intimidation, discriminatory comments, or public disclosure of private information.

## Expected conduct

- Be considerate and specific in feedback. Critique code and claims, not people.
- Assume mistakes are fixable and allow contributors to correct them.
- Respect differences in language, experience and technical background.
- Treat reported safety or security defects seriously and without retaliation.

## Unacceptable conduct

Harassment, threats, hate speech, repeated personal attacks, publishing another person's private information, unsolicited sexual content, and malicious interference with collaboration are not permitted.

## Enforcement

Maintainers may edit or remove inappropriate content, close threads, temporarily restrict interaction or ban repeat offenders. Decisions should be proportionate, documented privately as appropriate and applied consistently.

Report conduct concerns through a private maintainer contact method from the repository owner's GitHub profile. If one is not available, do not post personal or sensitive details publicly; request a private contact channel with a general, non-sensitive issue. Security vulnerabilities must use [SECURITY.md](SECURITY.md).
