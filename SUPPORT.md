# Support

Recall Watch is a volunteer-maintained, **unofficial** integration in beta. It is not an emergency alert system, regulator, food-safety hotline or substitute for official recall notices.

For setup questions, consult [README.md](README.md), [Installation](docs/HACS_MARKETPLACE.md) and [Troubleshooting](docs/TROUBLESHOOTING.md). For reproducible defects, open a GitHub issue using the bug report template and include sanitized logs. Use a feature request for enhancements. For confidential security concerns, use [SECURITY.md](SECURITY.md) instead of issues.

**For a suspected affected food product, follow the original official recall notice.** Recall Watch may miss records or mis-extract dates, batches, products and risks. Do not rely on the absence of an alert.
