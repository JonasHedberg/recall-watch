# Support

## Pre-release notice

The repository is not currently installable through HACS. Do not report installation failures until the complete source tree is published and the first validated beta release is available.

For bugs, use GitHub Issues and include Home Assistant version, Recall Watch version, configured source ID, steps to reproduce, and sanitized logs. For feature requests, explain the authority, jurisdiction and official feed/API reference.

Never share Home Assistant credentials, full private network addresses, personal data or secrets in public issues.

Recall Watch is volunteer-maintained and not affiliated with Home Assistant or any government authority. For product safety decisions, consult the original authority notice.
